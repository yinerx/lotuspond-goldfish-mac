# 池塘金鱼 · Pond Goldfish（macOS 动态壁纸）

一个原生 macOS 小程序：俯视一汪清澈的青绿色池塘，十几条锦鲤（红、红白、红白黑）在铺满鹅卵石和青苔的池底悠闲游动，水底有流动的焦散光纹，鱼会在池底投下柔和的影子。

- **落叶 / 花瓣**：会从天上飘落到水面，激起一圈圈涟漪，附近的鱼会被吓得四散游开，过几秒又好奇地游回来围着它看。
- **下雨**：细密的斜向雨丝 + 水面上大量小涟漪。
- **光照随真实时间变化**：白天明亮，黄昏偏暖，夜里是深蓝青色（焦散变弱、影子变深）。也可以手动调节太阳高度角。
- **窗口模式下可以点击水面**：会出现涟漪，附近的鱼会被吓跑。
- 所有画面（池底、鱼、荷叶、荷花、落叶、花瓣……）都是程序启动时用代码实时绘制的，**不依赖任何图片素材**。

> 根目录里的 `preview.png` 只是用 Python 画的“概念预览图”，用来提前看看大致风格，不是本程序的真实截图。

## 运行环境

- macOS 14（Sonoma）或更新版本，Apple 芯片或 Intel 都可以
- 需要安装 **Xcode**（推荐，App Store 免费下载），或至少安装命令行工具：`xcode-select --install`

## 怎么运行

### 方法一：用 Xcode（最简单）

1. 解压后，**双击 `Package.swift`**，Xcode 会自动打开这个项目。
2. 等 Xcode 左上角的“正在索引/解析包”结束。
3. 顶部运行目标选 `PondGoldfish` → `My Mac`，点 ▶︎（或按 ⌘R）。

### 方法二：终端打包成 App

```bash
cd PondGoldfish
bash build_app.sh
open "build/池塘金鱼.app"
```

> 注：从 GitHub 下载的 `build_app.sh` 可能没有可执行权限，所以用 `bash build_app.sh` 运行（或先 `chmod +x build_app.sh`）。

脚本会执行 `swift build -c release`，组装出 `build/池塘金鱼.app`（带图标、`LSUIElement`、bundle id `com.yiner.pondgoldfish`），并做 ad-hoc 签名（`codesign --force --deep -s -`）。可以把它拖进「应用程序」文件夹，以后像普通 App 一样双击打开。

也可以直接 `swift run`（不打包，适合调试）。

> 如果第一次打开 .app 时提示“无法验证开发者”：在 Finder 里**右键 → 打开**，再点“打开”即可（因为是本机 ad-hoc 签名，不是 App Store 签名）。

## 怎么用

程序启动后，**屏幕右上角菜单栏会出现一条小鱼图标 🐟**（SF Symbol `fish.fill`），所有操作都在这里：

| 菜单项 | 作用 |
| --- | --- |
| 切换模式 | 在「窗口模式」和「桌面壁纸模式」之间切换 |
| 显示池塘窗口 | 窗口模式下，关掉窗口后再把它叫出来 |
| 设置… | 打开设置面板 |
| 暂停动画 / 继续动画 | 暂停或继续渲染 |
| 落下一片叶子 / 花瓣 | 立刻触发一次落叶 / 落花（想马上看效果时用） |
| 下雨 | 开关下雨 |
| 检查更新… | 去 GitHub Releases 查看有没有新版本 |
| 退出 | 退出程序 |

### 切换到桌面壁纸模式

菜单栏小鱼 → **切换模式**。每块屏幕会各铺一个全屏的池塘窗口，放在桌面层（系统壁纸之上、桌面图标之下），在所有桌面空间（Space）都显示，鼠标会直接穿透（桌面图标照常可以点）。此模式下 Dock 里没有图标，只保留菜单栏小鱼。再点一次“切换模式”回到窗口模式。

所选模式会被记住，下次启动直接进入。

### 设置面板

| 设置 | 说明 |
| --- | --- |
| 水色 / 深水色 | 水的颜色和深水区颜色（默认 `#71E6C2` / `#1A5952`） |
| 水面高度 | 水越深，影子离鱼越远，深水色越浓 |
| 水面透明度 | 越高越清澈（焦散更明显），越低越浑 |
| 跟随现实时间 | 按当前时间和所在时区自动计算太阳高度角（默认纬度 31.2°，上海） |
| 太阳高度角 | 关掉“跟随现实时间”后手动调：-20°（夜）到 90°（正午直射） |
| 太阳光强度 | 光照、焦散和水面闪光的强弱 |
| 开启花瓣 / 开启落叶 / 下雨 | 事件开关 |
| 鱼的数量 | 5～30 条 |
| 帧率 / 使用电池时降低帧率 | 30 / 60 / 120 fps；用电池或开了低电量模式时自动降到 30fps |
| 自动检查更新 | 默认开启：启动时每天最多悄悄检查一次，有新版本才弹窗 |

所有设置都自动保存（UserDefaults），重启后保留。

### 省电

- 锁屏、显示器睡眠、切换用户时自动暂停渲染；
- 窗口模式下，池塘窗口被完全挡住或最小化时也会暂停；
- 使用电池时可自动降到 30fps。

### 检查更新

菜单栏小鱼 → **检查更新…**（或设置面板里的“检查更新…”按钮）会查询本仓库 GitHub Releases 的最新版本，和当前版本（`CFBundleShortVersionString`，由 `build_app.sh` 写入）比较：

- 有新版本时弹窗显示版本号和更新说明，可选 **下载新版本**（打开 .dmg 下载链接）/ **稍后** / **跳过这个版本**（自动检查时不再提醒这个版本）；
- 已是最新时提示“已经是最新版本（x.y.z）”；网络出错时提示检查失败。

设置面板里的 **自动检查更新**（默认开启）会在启动时每天最多检查一次，只有发现新版本才会弹窗。

## 下载安装（Release）

在 [Releases](https://github.com/yinerx/lotuspond-goldfish-mac/releases) 下载 `LotusPondGoldfish-x.y.z.dmg`，打开后把「池塘金鱼」拖进「应用程序」。因为只做了 ad-hoc 签名、没有 Apple 公证，第一次打开请 **右键 → 打开**（或到 系统设置 → 隐私与安全性 → 仍要打开）；仍打不开时可以在终端执行 `xattr -dr com.apple.quarantine "/Applications/池塘金鱼.app"`。

推送 `v*` 标签时，GitHub Actions（`.github/workflows/release.yml`）会自动编译、打包 DMG 并发布 Release。

## 已知限制

- 在 Linux 环境下写成；已经在 GitHub Actions 的 macOS 上编译通过（Xcode 26 / Swift 6.2），但**还没有在真机上运行验证过画面效果**，如有问题欢迎反馈。
- 桌面壁纸模式用的是“放在桌面层的窗口”，不是替换系统壁纸：系统设置里的壁纸不会改变；如果 macOS 的“点按墙纸以显示桌面”、台前调度等功能开启，可能会把它和其它窗口一起移开。
- 少数系统版本里桌面层窗口可能出现在系统壁纸下面（看不到池塘）。这种情况请告诉我，可以把窗口层级调高一级（`PondWindowManager.swift` 里的 `.desktopWindow` 改成 `+1`）。
- 壁纸模式下不能点击水面（鼠标穿透给桌面图标）；点水互动只在窗口模式下有效。
- 太阳位置用时区推算经度，纬度默认上海（31.2°），没有申请定位权限，所以日出日落时间会有十几分钟的误差。
- 多块屏幕时，每块屏幕都是一个独立的池塘，鱼不会跨屏游动。
- 调整窗口大小时，池底花纹会在停止拖动约半秒后重新绘制。
- 打包脚本只编译本机架构（Apple 芯片就是 arm64），不是通用二进制。

## 代码结构

```
Sources/PondGoldfish/
├── PondGoldfishApp.swift     程序入口（@main，纯 AppKit）
├── AppDelegate.swift         菜单栏图标、菜单、模式切换、锁屏/电池感知
├── PondWindowManager.swift   桌面壁纸窗口（每块屏幕一个）/ 普通窗口
├── SettingsView.swift        SwiftUI 设置面板 + 悬浮窗口
├── PondSettings.swift        所有设置（UserDefaults 持久化）
├── PondScene.swift           SpriteKit 场景：分层、光照、阴影、事件、涟漪、雨
├── Fish.swift                锦鲤：脊椎链 + 网格变形弯曲身体、转向/受惊/好奇行为
├── FishArt.swift             用 Core Graphics 画锦鲤花纹、尾鳍、胸鳍、阴影
├── PondArt.swift             池底（石子/青苔/石头/水草）、深度图、荷叶、荷花、落叶、花瓣、涟漪纹理
├── Painter.swift             Core Graphics / Core Image 绘图小工具
├── Shaders.swift             SKShader：焦散 + 折射抖动、深水雾、水面闪光
├── SunModel.swift            太阳高度角/方位角计算（NOAA 公式）→ 光照参数
├── UpdateChecker.swift       检查更新（GitHub Releases）+ 版本号比较
└── Utils.swift               向量、颜色、随机数
```
